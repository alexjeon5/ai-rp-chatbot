# AI 롤플레이 & 어시스턴트

로컬 모델과 API 를 오가며 쓰는 개인용 AI 채팅 앱

캐릭터을 만들어 두고, 원하는 엔진으로 대화하는 1인용 웹앱입니다.
같은 대화를 **LM Studio(로컬)** 로 돌리다가 **Gemini / OpenAI / Anthropic** 으로 갈아탈 수 있습니다.

```
브라우저 ──▶ Node 서버(프록시 + 저장소) ──▶ LM Studio / Gemini / OpenAI / Anthropic
```

브라우저가 AI 서버를 직접 부르지 않고 Node 서버를 거칩니다. 덕분에
CORS·혼합콘텐츠 문제가 없고, API 키가 브라우저에 노출되지 않습니다.

설치와 사용법을 처음부터 따라가려면 [GUIDE.md](GUIDE.md) 를 보세요.
소스 코드 구조와 확장 방법은 [DEVELOPER.md](DEVELOPER.md) 에 따로 정리했습니다.
아래는 요약입니다.

## 실행

```bash
npm install
npm start          # http://127.0.0.1:5173
```

포트나 바인딩 주소를 바꾸려면 `PORT=8080 HOST=0.0.0.0 npm start`.
데이터는 `data` 폴더에 항목별 파일로 쌓입니다. 이 폴더만 백업하면 전부 보존됩니다.

```
data/settings.json        엔진·키·대화 모드·테마
data/characters/<id>.json 캐릭터 하나가 파일 하나
data/personas/<id>.json   페르소나
data/chats/<id>.json      대화 하나가 파일 하나
```

예전 `db.json` 이 있으면 처음 켤 때 자동으로 쪼개지고, 원본은 `db.json.migrated` 로 남습니다.

## 두 가지 모드

사이드바 맨 위 탭으로 오갑니다.

- **롤플레이** — 캐릭터와 대화 모드을 쓰는 원래 모드
- **어시스턴트** — 캐릭터 없이 쓰는 일반 AI 채팅. 코드 블록이 렌더링되고, 온도가 낮게 잡혀 있습니다.
  입력창 아래 토글로 **생각** 과 **웹 검색** 을 켜고 끕니다. 사고 과정은 접힌 채로 표시됩니다

엔진은 두 모드가 공유합니다. 샘플링 값과 시스템 프롬프트만 따로 갑니다.

## 설정 창

설정 창은 왼쪽 탭으로 나뉩니다. 탭을 오가며 고친 뒤 **저장** 한 번으로 모두 반영되고, **취소** 하면 모두 버려집니다.

| 탭 | 들어 있는 것 |
|---|---|
| 엔진 | 사용할 엔진·주소·키·모델·컨텍스트 길이, 커스텀 엔진 추가, 감춰 둔 모델 |
| 응답 생성 | 온도·top_k·반복 억제·응답 길이·최대 메시지 수 |
| 대화 모드 | 모드 편집(시스템 프롬프트), 새 대화 때 모드 묻기, 성인 전용 표시 |
| 어시스턴트 | 어시스턴트 모드 프롬프트와 샘플링 값 |
| 이미지 | ComfyUI 장면 그리기 |
| 화면 | 메시지 표기법 토글, 테마 색·글꼴 |
| 개발자 | 조사 교정, 성인 모드 엔진 제한, 시스템 프롬프트·통신 로그 보기 |
| 백업/복원 | 백업 내려받기, 백업 불러오기 |

## 엔진 설정

설정 시트에서 엔진을 고르고 주소·키·모델을 넣은 뒤 **불러오기**로 모델 목록을 받아옵니다.

| 엔진 | 주소 | 키 |
|---|---|---|
| LM Studio | `http://localhost:1234/v1` | 필요 없음 |
| OpenAI | `https://api.openai.com/v1` | `sk-...` |
| Anthropic | `https://api.anthropic.com/v1` | `sk-ant-...` |
| Gemini | `https://generativelanguage.googleapis.com/v1beta` | AI Studio 키 |
| Ollama (클라우드) | `https://ollama.com/v1` | [ollama.com/settings/keys](https://ollama.com/settings/keys) 에서 만든 키 |
| Ollama (로컬) | `http://localhost:11434/v1` | 필요 없음 |

LM Studio는 Developer 탭에서 **Start Server** 를 눌러야 열립니다. 앱을 다른 기기(라즈베리파이 등)에서
돌린다면 LM Studio 쪽 "Serve on Local Network" 를 켜고 주소를 `http://<PC-IP>:1234/v1` 로 바꾸세요.

모델 이름은 시간이 지나면 바뀌므로, 기본값 대신 **불러오기**로 받은 목록에서 고르는 쪽이 안전합니다.

## Gemma 4 26B A4B (uncensored-heretic) 로 돌리기

MoE 모델이라 총 25.2B 중 한 번에 3.8B 만 활성화됩니다. 26B라는 숫자보다 훨씬 가볍게 돌아갑니다.

### 어떤 양자화를 받을까

| VRAM | 권장 | 비고 |
|---|---|---|
| 24GB | Q6_K (22.6GB) 또는 Q5_K_M (19.1GB) | 컨텍스트 여유까지 보면 Q5_K_M 이 편합니다 |
| 16GB | Q4_K_M (16.8GB) | 일부는 RAM 으로 넘어갑니다. 아래 전문가 오프로드를 켜세요 |
| 12GB 이하 | Q4_K_M + 전문가 오프로드 | 시스템 RAM 32GB 이상 권장 |

`mmproj` 파일은 이미지 입력용입니다. 텍스트 롤플레이만 할 거면 받지 않아도 됩니다.

VRAM 이 모자라면 LM Studio 의 **Force MoE expert weights onto CPU** 를 켜세요. 어텐션만 GPU 에 두고
전문가 가중치는 RAM 에 둡니다. 활성 파라미터가 3.8B 뿐이라 이렇게 해도 체감 속도가 크게 떨어지지 않습니다.

### RTX 5080 (16GB) 기준 설정

Q4_K_M 이 16.8GB 라 16GB 에 딱 안 들어갑니다. 두 갈래 중 하나를 고르세요.

| 방법 | 설정 | 특징 |
|---|---|---|
| Q4_K_M + 일부 CPU | GPU 레이어를 30 에서 조금씩 내려 로드될 때까지 | 품질 유지, 속도 약간 손해 |
| Q3_K_L (13.8GB) | 전부 GPU | 가장 빠름, 품질 약간 손해 |

MoE 라 한 번에 3.8B 만 돌아서, 레이어 몇 개가 CPU 로 넘어가도 체감 손해가 크지 않습니다.
먼저 Q4_K_M 으로 해 보고 느리면 Q3_K_L 로 내려가는 순서를 권합니다. 시스템 RAM 은 32GB 이상이 편합니다.

같이 켜 둘 것:

- **Flash Attention** 켜기
- **KV Cache Quantization** Q8 — 이걸 켜야 16GB 에서 컨텍스트 16K 가 나옵니다
- **Context Length** 16384
- 앱 설정의 LM Studio *컨텍스트 길이* 를 16384 로 맞춰 두면, 앱이 토큰을 어림해 16K 안에 들어가는 만큼만 보냅니다

5080 은 Blackwell 이라 구버전 CUDA 런타임에서는 모델이 안 올라가거나 CPU 로 떨어집니다.
로드가 실패하면 LM Studio 를 최신으로 올리고 Runtime 탭에서 CUDA 런타임도 갱신하세요.

### LM Studio 설정

- **Context Length**: 기본 4096 은 롤플레이에 금방 모자랍니다. 8192~32768 로 올리세요. 모델 자체는 256K 까지 되지만 KV 캐시가 VRAM 을 크게 먹습니다
- **Flash Attention**: 켜기
- **KV Cache Quantization**: Q8 로 두면 같은 VRAM 으로 컨텍스트를 두 배 가까이 늘릴 수 있습니다
- 앱 설정의 엔진 *컨텍스트 길이* 를 LM Studio 의 Context Length 와 같게 맞추세요. 앱이 그 한도 안에서 최근 대화부터 채워 보냅니다

### thinking 은 꺼진 상태로 씁니다

Gemma 4 는 시스템 프롬프트 맨 앞에 `<|think|>` 토큰이 있을 때만 사고 모드로 들어갑니다.
이 앱은 그 토큰을 넣지 않으므로 기본이 비사고 모드입니다.

다만 모델 카드에 적힌 대로, 사고를 꺼도 빈 사고 블록(`<|channel>thought` … `<channel|>`)은 그대로 출력됩니다.
`src/sanitize.js` 가 스트리밍 도중 이 블록을 걸러내므로 대사에 섞여 나오지 않습니다.
태그가 청크 경계에서 쪼개지는 경우까지 처리합니다.

### 샘플링

기본값이 Gemma 4 권장치(`temperature 1.0`, `top_p 0.95`, `top_k 64`)로 맞춰져 있습니다.
대사가 산만하면 온도를 0.8 근처로 내리고, 밋밋하면 1.1 까지 올려 보세요.

`top_k` 는 LM Studio·Anthropic·Gemini 에만 전달됩니다. OpenAI 는 모르는 파라미터로 보고 400 을 내기 때문에 빼고 보냅니다.

### 이 모델의 성질

Heretic 으로 거부 응답을 걷어낸 버전입니다. 제작자 측정으로 거부율 100/100 → 11/100,
대신 MMLU 가 82.5% → 80.8% 로 내려갔고 특히 법률·도덕 판단 항목의 하락이 큽니다.
롤플레이 문장력에는 거의 영향이 없지만, 안전장치가 빠진 만큼 무엇을 요청하든 그대로 따른다는 점은 알고 쓰세요.
같은 대화를 API 엔진으로 바꿔 돌리면 그쪽 정책이 다시 적용됩니다.


## 대화 모드

시스템 프롬프트를 여러 벌 저장해 두고 설정에서 골라 쓸 수 있습니다. 기본으로 여덟 개가 들어 있고,
**일반 셋이 먼저, 성인 셋이 뒤에** 오도록 목록 어디서나 같은 순서로 정렬됩니다.
새 대화를 열 때 뜨는 모드 선택 창은 **일반 / 성인** 탭으로 나뉘어, 한 번에 한쪽만 보입니다.
지난번에 고른 모드가 있는 쪽 탭으로 열리고, 성인 탭은 지금 엔진이 로컬이 아니면 미리 경고합니다.

- **롤플레이** — `*별표*` 로 행동, `"따옴표"` 로 대사. 한 번에 2~5문장의 짧은 호흡
- **소설 모드** — `(괄호)` 로 장면 묘사, `이름: "대사"` 로 화자 구분. 길고 촘촘한 서술
- **연출 모드** — 내 페르소나가 등장하지 않습니다. 상황만 지시하면 AI 가 주인공까지 전부 서술합니다
- **메신저 모드** — 묘사 없이 휴대폰 문자만 주고받습니다. 한 줄이 문자 하나이고, 화면에는 말풍선으로 보입니다
- **성인 롤플레이** — 롤플레이와 같은 표기, 성인 소재 허용 🔒
- **성인 소설 모드** — 소설 모드와 같은 표기, 성인 소재 허용 🔒
- **성인 연출 모드** — 연출 모드와 같은 표기, 성인 소재 허용 🔒
- **성인 메신저 모드** — 메신저 모드와 같은 형식, 성인 소재 허용 🔒

모드에 *성인 전용* 표시를 달면 그 모드를 쓰는 대화는 기본적으로 LM Studio 등 로컬 엔진으로만 나갑니다. 외부 API 로는 전송되지 않습니다.
클라우드 엔진에서도 쓰고 싶다면 *설정 → 개발자 탭 → 성인 모드 엔진 제한* 에서 경고를 확인한 뒤 풀 수 있습니다 (평소에는 숨겨져 있습니다).
이 경우 대화 내용이 그 회사 서버로 전송되고, 각사 이용 약관에 따라 거부되거나 계정이 제한될 수 있습니다.
대화마다 어떤 모드를 쓰는지 따로 기억하므로, 같은 캐릭터로 일반 대화와 성인 대화를 나눠 둘 수 있습니다.
목록에서는 **19** 배지로 구분되고, *성인 숨기기* 으로 감출 수 있습니다.

**새로 만들기**로 직접 쓴 프롬프트를 추가할 수 있습니다. 자리표시자는 이렇게 채워집니다.

| 자리표시자 | 들어가는 값 |
|---|---|
| `{{char}}` / `{{user}}` | 캐릭터 이름 / 내 페르소나 이름 |
| `{{description}}` `{{personality}}` `{{speech}}` `{{scenario}}` | 캐릭터의 각 항목 |
| `{{persona}}` | 페르소나 소개 |

비어 있는 항목은 라벨이 붙은 줄까지 통째로 빠집니다. `{{char}}` 가 한 번도 없는 모드에는
캐릭터 블록이 맨 뒤에 자동으로 붙으므로, 자리표시자를 전혀 모르는 프롬프트를 그대로 붙여 넣어도 캐릭터 정보가 반영됩니다.

화면은 두 표기법을 모두 알아봅니다. `*별표*` 와 `(괄호)` 는 묘사체로, 줄 맨 앞의 `이름:` 은 화자 라벨로 렌더링됩니다.
따라서 모드를 바꿔도 화면 설정을 따로 건드릴 필요가 없습니다.


## 장면 그리기 (ComfyUI)

같은 PC 나 LAN 에서 도는 ComfyUI 로 답변 장면을 그립니다. 설정 → **이미지** 탭에서 켜면 답변마다 **🎨 그리기** 버튼이 생깁니다.

1. 지금 LLM 이 장면을 영어 Danbooru 태그로 옮깁니다 (성인 대화는 로컬 엔진으로만)
   - 기본으로 **그릴 태그 확인** 창에서 태그를 먼저 보여 주고, 고친 뒤 그리기를 눌러야 그립니다. 창의 *다음부터 검토하지 않고 바로 그리기* 나 설정 → 이미지 탭의 *그리기 전에 태그 검토하기* 로 끌 수 있습니다
2. 앞에 붙일 품질 태그 + 캐릭터의 **외형 태그** + 장면 태그를 합쳐 ComfyUI 에 보냅니다
3. 다 그리면 `data/images/<대화 id>/` 에 저장하고 답변 아래에 보여 줍니다. 그림마다 *다시 그리기*(다른 시드), *태그 고쳐 그리기*, *삭제*
4. 그림을 누르면 대화 창 위에 크게 띄웁니다. ←/→ 로 대화 속 다른 그림을 넘겨 보고, 바깥을 누르거나 Esc 로 닫습니다 (Ctrl·가운데 클릭은 새 탭)

- **권장 모델**: SDXL 애니메 계열(Illustrious XL, NoobAI-XL 파생). 태그로 외형을 고정하기 쉽고 LLM 과 GPU 를 나눠 쓸 만한 크기입니다. Pony 계열이면 앞에 붙일 태그를 `score_9, score_8_up, …` 로 바꾸세요
- **워크플로**: 기본 SDXL txt2img 가 들어 있어 체크포인트만 고르면 됩니다. 직접 짠 워크플로는 ComfyUI 의 *Save (API Format)* JSON 을 올리고, 값 칸에 `{{prompt}}` `{{negative}}` `{{seed}}` `{{width}}` `{{height}}` `{{steps}}` `{{cfg}}` `{{sampler}}` `{{scheduler}}` `{{checkpoint}}` 를 적어 두면 채워 넣습니다
- **캐릭터 외형 태그**: 캐릭터 창의 *외형 태그* 칸 (`1girl, adult, long black hair, red eyes, gray hoodie`). 첫 그림은 캐릭터마다 고정 시드라 비슷한 얼굴로 나옵니다
- **같은 GPU 에서 LLM 과 함께 쓸 때**: LM Studio 에서 *Force MoE expert weights onto CPU* 를 켜 VRAM 을 비우고, *그린 뒤 ComfyUI 메모리 비우기* 를 켜 두세요
- **Docker**: ComfyUI 주소를 PC IP 로 쓰고(`http://192.168.0.10:8188`) compose 의 `LOCAL_ENGINE_HOSTS` 에 그 IP 를 넣습니다
- **필터**: 성인 대화용 *항상 붙일 태그 / 지울 태그 / 더할 네거티브* 는 설정의 이미지 탭에서 직접 고칩니다. 미성년으로 읽히는 표현은 **모든 대화에서** 고정으로 막히며(설정으로 끌 수 없음), 나오면 그림을 그리지 않습니다
- 그림 파일은 백업 JSON 에 들어가지 않습니다. `data` 폴더를 복사하면 함께 보존됩니다

## 캐릭터 만들기

| 칸 | 쓰임 |
|---|---|
| 성격 / 말투 | 연기의 뼈대. 가장 큰 영향을 줍니다 |
| 배경과 상황 | 첫 장면의 무대 설정 |
| 첫 대사 | 대화를 열 때 자동으로 놓이는 첫 메시지 |
| 대화 예시 | 말투를 흉내 낼 본보기. 2~4턴이면 충분합니다 |
| 추가 설정 | 세계관 규칙, 관계도, 금기 |

`{{char}}` 는 캐릭터 이름, `{{user}}` 는 내 페르소나 이름으로 바뀝니다.
뒤에 붙은 조사는 받침에 맞춰 자동으로 고쳐집니다 — `{{char}}가` 를 써 두면 "유하린이", "루나가" 로 나옵니다.

캐릭터를 **클릭**하면 어떤 모드로 시작할지 묻습니다. **우클릭(또는 Shift+클릭)** 하면 편집 창이 열립니다.

캐릭터 창에서 저장 대신 **이번만 쓰기** 를 누르면 목록에 남기지 않는 1회성 캐릭터로 대화를 시작합니다.
마음에 들면 대화 상단의 **캐릭터 저장** 으로 목록에 옮길 수 있습니다.

**기본 캐릭터** 버튼을 누르면 내장 캐릭터 여섯(일상 둘, 친한 동생 하나, 성인 모드용 셋)이 들어옵니다.
전부 20~21세이고 전원 여성 캐릭터입니다. 이미 있는 이름은 건너뛰므로 여러 번 눌러도 중복되지 않습니다.

### 줄글로 적고 AI 에게 맡기기

캐릭터 창 맨 위에 설명을 줄글로 적고 **AI 로 채우기** 를 누르면, 지금 선택된 엔진이
아래 칸(이름·태그·성격·말투·배경·첫 대사·대화 예시)을 한꺼번에 채웁니다.
"밤에만 문을 여는 헌책방 주인. 말수가 적은데 책 얘기만 나오면 길어진다" 정도면 충분합니다.

이미 손으로 채워 둔 칸은 **정해진 설정으로 모델에 함께 넘어가고, 응답이 덮어쓰지 않습니다.**
이름만 정해 두고 나머지를 맡기거나, 성격만 다시 뽑는 식으로 쓸 수 있습니다.
채워진 내용은 그냥 입력값이라 얼마든지 고친 뒤 저장하면 됩니다.

성인 소재가 섞인 설정은 로컬 엔진(LM Studio)을 골라 두고 누르는 편이 안전합니다 — 이 요청은
지금 선택된 엔진으로 그대로 나갑니다.

다른 AI에게 캐릭터 시트를 대신 만들어 달라고 할 때 쓸 프롬프트는 [GUIDE.md](GUIDE.md) 6절에 있습니다.

## 랜덤 페르소나

페르소나 시트의 **🎲 랜덤** 을 누르면 이름·나이대·직업·외모·성격·말투·사연을 표에서 굴려
태그 조합을 만듭니다. 칩 하나를 누르면 그 항목만 다시 굴러가고, 나머지는 그대로 남습니다.
(성별을 다시 굴리면 이름도 따라 바뀝니다.)

페르소나 시트의 **성인 페르소나** 체크박스를 켜면 태그가 완전히 분리된 풀에서 나옵니다
(나이대는 20대부터만 나오고, 관계·연애 쪽 태그가 섞입니다). 체크박스를 바꾸면 지금 뽑힌
태그는 버려지고 다시 시작합니다 — 두 풀이 섞이지 않게 하기 위해서입니다.

**문장 만들기** 를 누르면 그 태그를 지금 선택된 엔진에 넘겨 소개 한 문단을 받아 옵니다.
성인 페르소나는 대화의 성인 모드와 같은 규칙으로 **기본적으로 로컬(LM Studio) 엔진으로만** 나갑니다 —
클라우드 허용을 켜지 않은 채 외부 API 가 선택되어 있으면 태그만으로 만든 문장으로 대신 채워지고, 이유가 함께 표시됩니다.
이름·소개 칸이 채워지므로 손으로 고친 뒤 **페르소나 추가** 로 목록에 넣으면 됩니다.

엔진이 설정되지 않았거나 호출이 실패하면 태그만 이어 붙인 문장이 대신 들어가고,
왜 그렇게 됐는지 아래에 한 줄로 표시됩니다. 항목을 더 넣고 싶으면 `src/persona-seeds.js` 의
`POOLS` 배열에 문자열만 추가하세요.

## 조작

- 입력창 아래 선택기로 엔진을 바로 바꿉니다. 설정을 열 필요가 없습니다
- 모델이 같은 말을 되풀이하면 감지해서 생성을 멈춥니다 (설정의 *반복 억제* 로 조절)
- Enter 전송, Shift+Enter 줄바꿈 (한글 조합 중에는 전송되지 않습니다)
- `*별표*` 는 행동 묘사, `"따옴표"` 는 대사로 렌더링됩니다
- 메시지에 마우스를 올리면 수정 / 복사 / 삭제가 나옵니다. AI 응답을 직접 손보면 그 내용이 이후 맥락에 그대로 반영됩니다
- **재전송** 은 마지막 답변의 다른 버전을 씁니다. 이전 버전은 답변 아래 **‹ 2 / 3 ›** 으로 넘겨볼 수 있고, 마지막 장에서 › 를 누르면 새 버전을 씁니다
- **이어쓰기** 는 최대 길이에서 잘린 답변 끝에 이어서 씁니다
- 입력창 아래 **✍ 대신 쓰기** 는 내 다음 차례를 AI 가 초안으로 입력창에 써 줍니다. 보내지 않으니 고친 뒤 보내면 됩니다. 입력창에 "화난 척하지만 반가움" 처럼 방향을 적어 두고 누르면 그 방향으로 씁니다
- 대화 상단 **기억·노트** — 세 가지를 다룹니다
  - **기억해 둔 사실**: 답변 4개마다 AI 가 뒤에서 약속·호칭·취향 같은 사실을 한 줄씩 뽑아 둡니다. 새 메시지를 보내면 확인은 미뤄져 답변이 늦어지지 않습니다. 📌 고정·직접 수정한 항목은 AI 가 건드리지 않고, 근거 메시지를 지우거나 다른 답변으로 넘기면 그 항목도 치웁니다
  - **지금까지의 이야기**: 컨텍스트 한도 밖으로 밀려난 옛 대화의 요약 (자동/수동)
- 입력창 아래 **컨텍스트 게이지** — 한도 가운데 설정·기억 / 대화 / 답변 여유가 얼마씩인지, 옛 메시지가 몇 개 잘렸는지 보여 줍니다. 대화는 메시지 개수가 아니라 토큰으로 어림해 한도 안에 들어가는 만큼 최근 것부터 보냅니다. 엔진이 실제 토큰 수를 알려 주면 어림을 스스로 보정합니다
  - **작가 노트**: 매 턴 몰래 붙는 진행 지시
- 대화 상단 **등장인물** — 다른 캐릭터를 최대 8명까지 같은 장면에 부릅니다. AI 가 인물끼리 말을 주고받게 하고 줄 앞에 이름을 붙입니다

## Docker

```bash
docker compose up -d --build
```

`docker-compose.yml` 을 먼저 열어 아래 두 가지를 고쳐야 합니다.

- `LOCAL_ENGINE_HOSTS` — LM Studio 가 도는 PC 의 LAN IP. 여기 적힌 주소로만 요청이 나갑니다
- 포트는 `5173:5173`으로 모든 인터페이스에 묶여 있어, 같은 LAN 의 다른 기기에서 `<파이IP>:5173`으로 바로 접속할 수 있습니다. 프록시로 오는 트래픽만 받고 싶다면 `127.0.0.1:5173:5173`으로 되돌리세요

API 키는 `.env` 파일에 두면 `data/settings.json` 에 평문으로 남지 않습니다.

```
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GEMINI_API_KEY=AIza...
OLLAMA_API_KEY=...
```

환경변수로 넣은 키는 설정 화면에서 회색으로 잠기고, 화면에서 바꿀 수 없습니다.

## 보안

혼자 `127.0.0.1` 로 쓸 때는 신경 쓸 것이 없지만, 라즈베리파이에 올려 도메인으로 여는 순간
이 앱은 **API 키를 들고 있고 대신 요청을 보내 주는 서버**가 됩니다. 아래가 들어가 있습니다.

| 장치 | 하는 일 |
|---|---|
| 키 마스킹 | `GET /api/settings` 가 키를 내보내지 않습니다. 들어 있는지 여부만 알려 줍니다 |
| 환경변수 키 | `OPENAI_API_KEY` 등이 있으면 그쪽이 우선이고, 설정 파일에 기록되지 않습니다 |
| 주소 허용 목록 | 엔진 `baseUrl` 을 아무 데나 못 바꿉니다. 공식 API 주소와 `LOCAL_ENGINE_HOSTS` 에 적은 곳만 허용 |
| 요청 제한 | 생성 60초당 30회, 모델 목록 60초당 20회 |
| 같은 출처 확인 | 다른 사이트가 브라우저를 시켜 보내는 변경 요청을 막습니다 |
| 비 root 실행 | 컨테이너가 `node` 사용자로 돕니다 |

**이것들은 2차 방어입니다.** 앱 자체에는 로그인이 없으므로, 앞단에 인증을 반드시 두세요.
Cloudflare Access 나 Nginx Proxy Manager 의 Access List 로 본인만 통과시키는 식입니다.

### 주소 허용 목록에 대해

서버가 대신 요청을 보내 주는 구조라, `baseUrl` 을 자유롭게 바꿀 수 있으면 이 서버가 그대로
내부망 스캐너가 됩니다. 그래서 미리 적어 둔 곳으로만 나갑니다.

```yaml
environment:
  LOCAL_ENGINE_HOSTS: "192.168.0.10"      # LM Studio 가 도는 PC
  EXTRA_ENGINE_HOSTS: "openrouter.ai"     # 외부 엔진을 추가로 쓸 때만
```

허용 목록에 없는 주소를 넣으면 저장 단계에서 거부되고, 어디를 고쳐야 하는지 알려 줍니다.
`data/settings.json` 을 직접 고쳐 넣어도 실제 요청 직전에 한 번 더 걸러집니다.

### 여전히 남는 것

- `data/settings.json` 에 저장하는 방식을 쓰면 키는 평문입니다. `.env` 쪽을 권합니다
- 대화 내용도 평문 JSON 입니다. 파이의 디스크가 통째로 털리면 그대로 읽힙니다
- 앱에는 사용자 개념이 없습니다. 앞단 인증을 통과한 사람은 전부 같은 권한을 가집니다
