# AI 롤플레이 & 어시스턴트

로컬 모델과 클라우드 API 를 오가며 쓰는 개인용 AI 채팅 웹앱입니다.
캐릭터와 롤플레이를 하거나, 캐릭터 없이 일반 어시스턴트로 씁니다.

```
브라우저 ──▶ Node 서버 (프록시 + 저장소) ──▶ LM Studio · Ollama · Gemini · OpenAI · Anthropic · Vercel AI Gateway
```

## 주요 기능

- **엔진 전환** — 같은 대화를 LM Studio(로컬)로 돌리다가 API 엔진으로 바꿔 이어 갑니다. API 키는 서버에만 있고 브라우저로 나가지 않습니다
- **캐릭터와 페르소나** — 캐릭터 시트를 직접 쓰거나 줄글 설명으로 AI 에게 채우게 합니다. 기본 캐릭터 8명과 연출 지시용 '감독' 페르소나가 들어 있습니다
- **대화 모드** — 롤플레이 · 소설 · 연출 · 메신저. 모드마다 시스템 프롬프트를 고쳐 쓰거나 새로 만듭니다
- **긴 대화 관리** — 컨텍스트 한도에 맞춰 보낼 대화를 고르고, 밀려난 대화는 요약하고, 중요한 사실은 따로 기억해 둡니다
- **대화 도구** — 다시 받기 · 이어쓰기 · 대신 쓰기, 여러 인물 등장, 작가 노트, 보관함
- **어시스턴트 모드** — 마크다운 · 코드 블록, 생각(추론) 토글, 웹 검색과 출처
- **장면 그리기** — ComfyUI 와 연결해 답변 장면을 그림으로
- **여럿이 쓰기** — 로그인, 계정별 데이터, Docker 배포, 요청 제한 · 주소 허용 목록 같은 보안 장치
- **디스코드 봇** — 채널에서 스레드를 열어 내 캐릭터와 대화. 웹과 같은 계정·대화를 씁니다

성인 전용으로 표시한 대화 모드는 기본적으로 로컬 엔진으로만 보냅니다.

## 빠르게 시작하기

Node.js 20 이상이 필요합니다.

```bash
git clone https://github.com/alexjeon5/ai-rp-chatbot.git
cd ai-rp-chatbot
npm install
npm run user -- add <아이디>   # 첫 계정. 비밀번호를 두 번 묻습니다
npm start                     # http://127.0.0.1:5173
```

로그인한 뒤 **설정 → 엔진** 에서 주소 · 키를 넣고 **불러오기** 로 모델을 고르면 됩니다.
LM Studio 는 Developer 탭에서 **Start Server** 를 눌러 두세요 (기본 주소 `http://localhost:1234/v1`).

Docker 로 올리려면 `docker-compose.yml` 의 `LOCAL_ENGINE_HOSTS` 를 고친 뒤 `docker compose up -d --build`.
