      캐릭터 만들기

      어떤 캐릭터인지 줄글로 적으면 AI 가 아래 항목을 채웁니다. 이미 적어 둔 칸은 그대로 둡니다.

      {{char}}는 캐릭터 이름, {{user}}는 내 페르소나 이름으로 바뀝니다.

      내 페르소나

      대화에서 {{user}}로 불릴 나 자신입니다. 여러 개를 두고 골라 쓸 수 있습니다.

        태그를 굴려 뼈대를 잡고, 문장은 AI 가 씁니다. 칩을 누르면 그 항목만 다시 굴립니다.

          기억 · 작가 노트

          기억해 둔 사실 — 대화 중에 AI 가 자동으로 모읍니다

            약속·호칭·취향처럼 어긋나면 티 나는 사실을 한 줄씩 모읍니다. 📌 고정하거나 직접 고친 항목은 AI 가 바꾸지 않습니다. 근거가 된 메시지를 지우거나 다른 답변으로 넘기면 그 메시지에서 나온 항목도 치웁니다.

            컨텍스트 한도를 넘어 모델에게 더는 보내지 않는 옛 대화를 요약해 둔 것입니다. 시스템 프롬프트 끝에 붙어 매번 함께 갑니다. 틀린 곳은 직접 고쳐도 되고, 다음 요약 때도 유지됩니다.

            내 마지막 메시지 뒤에 몰래 덧붙여 보냅니다. 저장된 대화에는 남지 않고, 비워 두면 보내지 않습니다.

            등장인물

            고른 캐릭터들이 이 대화에 함께 나옵니다. AI 가 장면에 맞는 인물을 골라 서로 말을 주고받게 하고, 말하는 줄 앞에 이름을 붙입니다. 최대 8명까지 고를 수 있습니다.

              설정

              모델이 한 번에 받는 양입니다. LM Studio 는 모델을 올릴 때 정한 Context Length 와 같게 맞추세요. 이 한도 안에서 최근 대화부터 채워 보내고, 넘치는 옛 대화는 잘라 냅니다.

              엔진 추가

              Ollama, vLLM, llama.cpp, OpenRouter 등 OpenAI 호환 서버를 붙일 수 있습니다.

                감춰 둔 모델

                쓰려고 했으나 "없는 모델"이라고 거부당한 것들입니다. 목록에서 자동으로 빠집니다. 계정 상태가 바뀌었다면 지우고 다시 시도해 보세요.

                  top_k 는 LM Studio·Anthropic·Gemini 에만 전달됩니다. OpenAI 는 이 값을 받지 않습니다.
                  Anthropic 은 온도 상한이 1 이라, 1 을 넘겨 두면 1 로 잘라 보냅니다. LM Studio·Gemini 는 2 까지 받습니다.
                  반복 억제는 로컬 엔진에만 전달됩니다. 같은 말이 되풀이되면 1.15~1.2 까지 올려 보세요. 1 은 억제 없음입니다.

                  {{char}} {{user}} {{description}} {{personality}} {{speech}} {{scenario}} {{persona}} 자리에 캐릭터 정보가 들어갑니다. 비어 있는 항목은 줄째로 빠집니다. {{char}} 가 한 번도 없는 모드에는 캐릭터 블록이 맨 뒤에 자동으로 붙습니다.

                  지금 편집 중인 모드의 내용을 고른 기본 모드 원본으로 덮어씁니다. 저장을 눌러야 확정됩니다.

                  어시스턴트 모드는 캐릭터와 페르소나를 쓰지 않습니다. 이 프롬프트와 대화 내용만 보냅니다.

                  Docker 로 돌린다면 PC 주소(예: http://192.168.0.10:8188)를 쓰고, compose 의 LOCAL_ENGINE_HOSTS 에 그 IP 를 넣어 주세요.

                  워크플로

                  ComfyUI 에서 Save (API Format) 으로 내보낸 JSON 을 올리면 그대로 씁니다. 값 칸에 아래 자리표시자를 적어 두면 앱이 채웁니다.
                  {{prompt}} {{negative}} {{seed}} {{width}} {{height}} {{steps}} {{cfg}} {{sampler}} {{scheduler}} {{checkpoint}}

                  성인 대화 필터

                  성인 모드 대화에서 그릴 때만 적용됩니다. 쉼표로 구분하고, * 는 아무 글자나로 봅니다 (예: *blood*).

                  고정 차단 목록 — 모든 대화에 적용, 수정할 수 없습니다

                  미성년으로 읽힐 수 있는 표현입니다. 그림 태그에 하나라도 나오면 빼고 그리는 대신 그리지 않습니다. 다른 태그만으로도 어려 보이는 그림이 나올 수 있어서입니다. 일반 대화에도 적용되고, 아래 네거티브도 늘 함께 붙습니다.

                  메시지 표시 방식

                  모델이 내놓은 글을 화면에서 어떻게 꾸밀지 정합니다. 저장된 원문은 바뀌지 않습니다.

                  테마

                  CSS font-family 값을 그대로 씁니다. 설치된 글꼴이나 이미 불러온 웹폰트만 적용됩니다.

                  프롬프트

                  성인 모드 엔진 제한

                  성인 모드 대화와 성인 페르소나 생성은 기본적으로 로컬 주소의 엔진(LM Studio 등)으로만 보냅니다.

                  진단

                  이 대화에서 실제로 모델에 보내는 시스템 프롬프트 전문을 봅니다. 캐릭터 설정이 제대로 들어갔는지, 비어 있는 항목이 어떻게 빠졌는지 확인할 수 있습니다.

                  엔진과 주고받은 통신 기록입니다. 응답이 실패했을 때 어떤 요청이 어떤 상태 코드로 거부됐는지 여기서 확인할 수 있습니다. 대화 내용(시스템 프롬프트·메시지)은 담지 않습니다.

                  백업 내려받기

                  캐릭터·페르소나·대화와 설정(샘플링 값·대화 모드·어시스턴트 프롬프트·테마·표기법)을 JSON 파일 하나로 받습니다. 엔진 주소와 API 키는 담기지 않습니다.

                  백업 내려받기

                  백업 불러오기

                  내려받은 백업 파일을 지금 데이터에 합칩니다. 이미 있는 항목은 건너뛰고, 설정까지 덮어쓸지는 불러올 때 따로 묻습니다. 불러오면 이 창에서 저장하지 않은 입력은 버려집니다.

                  저장을 누르면 모든 탭의 변경이 한꺼번에 반영됩니다.

                  어떤 모드로 시작할까요

                    대화를 시작한 뒤에도 상단 선택기에서 바꿀 수 있습니다.

                    클라우드 엔진에서 성인 모드를 쓰기 전에

                    이 제한은 사고를 막으려고 걸어 둔 것입니다. 아래 내용을 읽고 직접 판단해 주세요.

                    • 대화 전체가 외부 회사 서버로 전송됩니다. 시스템 프롬프트, 캐릭터·페르소나 설정, 주고받은 메시지가 OpenAI · Anthropic · Google · Ollama 등 선택한 엔진의 회사로 넘어갑니다. 회사 정책에 따라 일정 기간 저장되고, 정책 위반 여부를 가리기 위해 사람이 검토할 수 있습니다.
                    • 대부분의 클라우드 서비스는 이용 약관으로 성적인 콘텐츠 생성을 제한합니다. 요청이 거부될 수 있고, 반복되면 API 키나 계정이 정지될 수 있습니다. 쓰는 서비스의 약관을 직접 확인하고, 그 책임은 사용하는 사람이 집니다.
                    • 거부된 요청에도 요금이 나갈 수 있습니다.
                    • 켜면 성인 대화의 답변뿐 아니라 요약·기억 정리, 대신 쓰기, 장면 그리기의 태그 변환, 성인 페르소나 문장 만들기도 선택한 클라우드 엔진으로 나갑니다.
                    • 성인 모드의 절대 규칙(등장인물은 모두 성인, 실존 인물 금지)과 그림의 고정 차단 목록은 그대로 적용됩니다.
